# ChatFlow

A full-stack real-time chat application built with React, Node.js, Express, MongoDB, and Socket.io.

## Features

* Real-time messaging
* JWT authentication
* Online/offline status
* Typing indicators
* User profiles
* Follow/friend requests
* Responsive UI

## Tech Stack

**Frontend:** React, Vite, Socket.io, Styled Components

**Backend:** Node.js, Express.js, MongoDB, Mongoose, Socket.io, JWT

## Run Locally

### Backend

```bash
cd chatflow-backend
npm install
npm start
```

### Frontend

```bash
cd chatflow-frontend
npm install
npm run dev
```
